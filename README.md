# دفترچه سرویس خودرو — نسخه‌ی آماده هاست (PWA)

این پوشه یک اپ وب پیشرو (PWA) کامل و مستقل است. تمام داده‌ها (خدمات، تعویض‌ها، کیلومتر)
در همان مرورگر کاربر و روی همان دستگاه ذخیره می‌شود (localStorage) — نیازی به سرور یا
دیتابیس نیست.

## فایل‌ها
- `index.html` — کل اپلیکیشن (رابط کاربری + منطق)
- `manifest.json` — مشخصات نصب (نام، آیکون، رنگ تم)
- `sw.js` — service worker برای کارکرد آفلاین
- `icons/icon-192.png`, `icons/icon-512.png` — آیکون اپ

## نحوه هاست کردن
هر هاست استاتیکی که HTTPS ارائه دهد کافی است (PWA بدون HTTPS نصب نمی‌شود؛ فقط
`http://localhost` استثناست). چند گزینه رایگان و ساده:

1. **GitHub Pages**: این پوشه را در یک ریپازیتوری push کنید، سپس از تنظیمات
   ریپازیتوری، Pages را روی شاخه‌ی موردنظر فعال کنید.
2. **Netlify / Vercel / Cloudflare Pages**: پوشه را drag & drop کنید یا به یک
   ریپازیتوری گیت متصل کنید؛ نیازی به build نیست (Static/No framework).
3. **هاست شخصی**: کل محتوای این پوشه را داخل یک زیرپوشه (یا ریشه‌ی دامنه) آپلود کنید.

نکته مهم: ساختار فایل‌ها باید دقیقاً همین‌طور کنار هم باقی بماند (مسیرهای
`icons/` و `manifest.json` و `sw.js` نسبی هستند).

## نصب روی گوشی
بعد از باز کردن آدرس سایت در مرورگر (Chrome/Safari):
- اندروید: منوی مرورگر → «افزودن به صفحه اصلی» / «Install app»
- آیفون (Safari): دکمه‌ی Share → «Add to Home Screen»

## پشتیبان‌گیری از داده‌ها
چون داده‌ها فقط روی همان مرورگر/دستگاه ذخیره می‌شوند، از منوی تنظیمات (آیکون
چرخ‌دنده بالای صفحه) می‌توانید:
- **دریافت فایل پشتیبان**: یک فایل JSON از کل اطلاعات دانلود کنید.
- **بازیابی از فایل پشتیبان**: همان فایل را روی همین دستگاه یا دستگاه دیگر
  بازیابی کنید — این تنها راه انتقال اطلاعات بین مرورگرها یا دستگاه‌های
  مختلف است.

## توسعه بیشتر (اختیاری)
اگر بعداً خواستید داده‌ها بین چند دستگاه به‌صورت خودکار همگام شوند، باید یک
بک‌اند/دیتابیس واقعی (مثل Firebase یا یک API شخصی) اضافه شود؛ نسخه فعلی
کاملاً local-first و بدون نیاز به سرور طراحی شده است.
